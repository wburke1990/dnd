# Plot balance — which threads belong to which player

Every thread we have written that is keyed to a particular PC, listed under that PC,
with where it lives and whether it has been run. Ensemble scenes that give every PC a
line are in their own section at the bottom; they are not counted as anyone's thread.

Status uses the frontmatter vocabulary — `played`, `ready`, `draft`, `idea` — plus
**unwritten** for a thread that exists in a character file and has no scene written for
it anywhere.

Rebuild this by hand when a thread is run. It is not generated.

  Company town, and no encounter goes there.

  Jasper the hell-tree ruling; **Blackacre now has the wreck on the sea leg**, and
  Aniess still has nothing keyed to her.
